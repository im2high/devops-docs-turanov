# Аварийное восстановление

1. Откройте последний запуск Publish documentation в GitHub Actions.
2. Проверьте журнал первого упавшего шага и устраните причину через Pull Request.
3. После слияния дождитесь успешных заданий `build` и `deploy`.
4. Откройте опубликованный сайт и проверьте версию на главной странице.

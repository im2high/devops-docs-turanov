# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Где искать причину |
|---|---|---|
| Неиспользуемая переменная | Красная проверка `pylint` в PR | Журнал шага Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Журнал `deploy-pages` и блок `permissions` |
| Битая ссылка | `mkdocs build --strict` завершается ошибкой | Журнал шага Build documentation |
| Старая версия после успешного деплоя | Workflow успешен, браузер показывает прежнее содержимое | URL окружения, время публикации и кэш браузера |

## Правило разбора

Зафиксируйте симптом, затронутый компонент, доказательство из журнала, причину, исправление и результат повторной проверки.
